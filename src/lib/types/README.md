# Types

Tipi TypeScript condivisi nel progetto.

Definire i tipi una volta sola qui e importarli dove servono.

Tipi previsti:
- `Section` — Una sezione del sito.
- `Topic` — Un topic all'interno di una sezione.
- `Comment` — Un commento (positivo o negativo).
- `OpinionState` — Stato derivato (NEUTRAL, MOSTLY_POSITIVE, ecc.).
