# Data

Contenuti del sito in file TypeScript.

Separare i dati dai componenti permette di modificare testi e commenti senza toccare il codice dei componenti.

File previsti:
- `sections.ts` — Le 3 sezioni (sostenibilità, sport, infrastrutture) e i loro topic.
- `comments.ts` — I commenti di ogni topic (3 positivi + 3 negativi).
